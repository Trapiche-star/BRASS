# BRASS - 하늘을 누비는 모험가 (Sky Voyager)

스팀펑크 세계관 3D 액션 어드벤처 게임

## 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 게임명 | 하늘을 누비는 모험가 (Sky Voyager) |
| 장르 | 3D 스타일리시 액션 + 보스 러시 |
| 세계관 | 스팀펑크 |
| 엔진 | Unity 6.3 LTS |
| 플랫폼 | PC |

## 게임 컨셉

하늘을 나는 탐사선을 타고 스팀펑크 세계를 탐험하며, 거대한 보스와 스타일리시한 전투를 벌이는 액션 어드벤처 게임.

## 전투 시스템

- **스타일리시 액션**: 콤보 / 회피 / 패링
- **무기 교체형 전투**: 무기에 따라 모션과 스킬이 변화
- 주인공 1인 고정 플레이

### 무기 목록

| 무기 | 스타일 | 소환 키 |
|------|--------|---------|
| 스패너 (기본) | 근-중거리, 근접 콤보 + 투척 (부메랑) | 기본 장착 |
| 배틀 액스 | 근거리, 고데미지 | [ |
| 원거리 무기 | 원거리, 견제/약점 사격 | ] |

## 보스: 하늘 유린자

- **외형**: 기계 + 코스믹 호러 혼합, 모독적인 외형. 탐사선을 덮칠 만큼 거대함
- **습성**: 탐사선을 습격하여 부품을 뜯어가고, 천천히 포식하는 포식자
- **전투 방식**: 탐사선 위에서 전투. 팔/손 부위를 공격하며, 조건 만족 시 보스 위로 올라타 핵을 파괴
- **페이즈**: 2페이즈 구성 (HP 50~60%에서 긴급 조작 QTE와 함께 전환)
- **핵 파괴**: 1페이즈 2회 + 2페이즈 1~2회, 총 3~4회
- **레퍼런스**: FF14 비스마르크 토벌전, FF14 둔 스카 1네임드, 아토믹 하트

## 상점 시스템

- **접근 방식**: 함장실 기계 또는 시스템 메뉴
- **배송**: 증기 드론 배송
- **재화**: 골드 (보스 처치 시 불필요한 부산물 자동 환산)

### 판매 품목

| 품목 | 설명 |
|------|------|
| 무기 강화 부품 | 초반 일부 판매, 이후 보스 파밍 |
| HP 포션 | 소/중/대 (소지 99개 제한) |
| 함선 수리재 | 거래처 해금 필요 (스토리용) |
| 판매용 아이템 | 보스 드랍 전용 판매 아이템 |

### 거래처 (3곳)

| 거래처 | 주요 취급 |
|--------|----------|
| A마을 (가장 가까움) | 수리재 |
| B마을 | 포션 |
| C마을 | 강화 부품 |

## 무기 강화

- 공격력 + 스킬 데미지 증가
- 2단계까지 (1강 → 2강)
- 실패 없음, 대신 재료가 점점 희귀해짐
- 기본금 500골드 기준 밸런싱
